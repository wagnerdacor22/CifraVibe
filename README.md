# 🎸 CifraVibe Pro

App web para exibição de cifras com acompanhamento rítmico (bateria eletrônica).
Ideal para músicos e professores disponibilizarem repertório a alunos via senhas únicas.

## 🔐 Funcionamento
- **Admin:** acessa com senha mestra, cadastra músicas e gera senhas de acesso.
- **Cliente:** recebe uma senha, ativa seu catálogo e visualiza as cifras com player de bateria integrado.

## 🚀 Publicação
Basta fazer o upload do `index.html` em qualquer servidor estático (GitHub Pages, Netlify, Vercel).

## 🛠️ Tecnologias
- HTML5, CSS3, JavaScript puro (Vanilla JS)
- Web Audio API para os ritmos de bateria
- LocalStorage para persistência dos dados
